## A. 正确性优先：折叠串 bug + 八条不变量（先于一切新功能）
### 🔴 A1. 折叠字符串常量 = 无头指针进 ARC 世界
三个修复点，一个都不能少：
| 位置 | 现状 | 修法 |
| --- | --- | --- |
| `expr(Binary)` 的 `foldedIsStr` 分支 | 发裸 C 字面量，无 16 字节头；且 `isOwned` 把它判成 owned | `if (arcMode) return internLit(n->foldedS);` |
| `zeroOf(String)` 的所有调用点 | `let s: string;`（无初始化）、string 函数落穿兜底，都发裸 `""` → cleanup/retain 崩 .rodata | 全部换 `zeroOfA`（Try 处已换 ✓，Let-无初始化和 emitFuncBody 兜底还没） |
| 全局常量 | `const FULL = "Lux" + "9";` 走折叠分支 → 同病 | 折叠分支修好即自动覆盖，但**回归测试必须包含这条** |
**测试**：`arc_folded.lux`——`let s = "a" + "b";`、`const F = "x" + "y"; let t = F;`、循环体内字面量拼接、`let s: string;`，跑 `--arc` + **ASan**。CI 的 ASan job 从此**加跑一遍 `--arc` 维度**——这类 bug 只有 ASan 能一秒现形。
### 🟠 A2. 截断区八条不变量逐条核销（dump 看不见 = 你必须自查）
| # | 不变量 | 自查点 |
| --- | --- | --- |
| 1 | **Return 引用类型走 coerceStore**（借用 retain / owned 转移） | 最致命。`return s;` 若走 coerceTo → cleanup 释放返回值 → 调用方悬垂 |
| 2 | **assignStmt 先存新值再释旧值** | 顺序反了则 `a[0] = a[0];` 自赋值即 UAF。补三个用例：`a[0]=a[0]` / `s=s` / `p.f=p.f` |
| 3 | cleanup 只挂 `arcMode && isRefTy` 的 let | 非 ARC 模式绝不许挂（靠 `lx_gc_enabled` 短路不算防御） |
| 4 | **参数方案配对** | 看代码是借用方案（callExpr 用 coerceTo、参数无 cleanup）——确认没有任何一半 retain 的残留 |
| 5 | **for-in 循环变量** | 数组元素是借用（无 cleanup ✓）；但 `for c in s` 的 `lx_str_char_at` 是 **owned**，borrow 方案下每字符泄一次。建议按可迭代对象区分：迭代 string 时循环变量挂 cleanup（值每轮新建，释放安全），迭代数组时不挂。嫌复杂就记入已知缺口，但 `arc.md` 要写明 |
| 6 | struct `cn_on_zero` 的生成 | StructLit 引用了它，确认每个 struct 都真的发射了（逐 ref 字段 release，嵌套递归） |
| 7 | litAnchor 位置 | litDefs 必须先于全局常量区和所有函数体 |
| 8 | print 路径临时串 | `println(string(x))` / `println(arr)` 的 toStrOf 结果无人释放——最热的泄漏路径。建议包一层语句表达式打印后 release；做不动就明确记入已知缺口 |
**`main(argv)` 的 argv 数组**是借用参数方案下的一次性泄漏（lx_argv_new 全 owned），记入已知缺口即可。

## B. 主菜：0.9.3 拍板过的三件事
### B1. 原生后端 free list（arc.md §2.3，本版最大工程）
- 尺寸分桶（16B…1MiB）、refs 头、归零链桶，照 §2.3 执行；
- **原生字面量是第一个设计点**：native 的字符串字面量在 .rodata，前面加不了头。建议方案：**启动时把字面量表拷进 bump 堆并置 `refs=-1`**（native_rt 初始化阶段做，一次性、便宜、语义与 C 后端完全对齐）；
- 数组 data 块的 realloc 旧块**必须还桶**（老话第四次：只管对象头不管 data 块 = 半成品 ARC）；
- 落地纪律照旧：先 C 后端全绿，再动 native，**不要同时动**；`--native --arc` 的明确报错随之解除。
### B2. `T?` 装箱回收
装箱槽的账要理清“谁拥有”：
- `let x: int? = int(s);` → 变量拥有箱，**cleanup 函数 = 释放内层引用值（若 elem 是 ref 类型）+ free 箱**（箱本身是裸 malloc，无头，直接 free）；
- 三个解包点（`?` 传播、`or` 兜底、`f!`/`int!`）都是**一次性消费者**：读完 `*o` 后释放内层 + free 箱——现在的实现三处都漏箱；
- `T?` 作为参数/返回值：沿用借用约定，箱由调用方的变量/临时清理负责。
### B3. 默认开启（放在一切全绿之后的最后一步）
- `--arc` 变默认，新增 `--no-arc` 退出阀；
- 全量测试矩阵（行为 + 差分 + 包 + REPL）**默认模式**全绿后才翻转；
- bench 前后对比跑一遍——retain/release 有开销，数字进 D6，无论好坏。
